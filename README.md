# TCC Checkpoint Dashboard (HDY)

หน้า Dashboard รายงานแบบไฟล์เดียว (static HTML) เปิดใช้งานผ่าน GitHub Pages ได้ทันที

## วิธีเปิดใช้งานบน GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository (ให้ `index.html` อยู่ที่ราก)
2. ไปที่ **Settings → Pages**
3. Source: **Deploy from a branch** → Branch: `main` / folder: `/ (root)` → **Save**
4. รอ 1–2 นาที แล้วเข้า `https://<username>.github.io/<repo-name>/`
